# Traffic-Signal-RL
Reinforcement Learning for Traffic Signal Control

# 강화학습 기반 공릉역 교차로 신호등 최적화

## 1. 프로젝트 개요

본 프로젝트는 실제 교통량 데이터를 기반으로 Q-Learning을 활용하여 교차로의 교통 신호를 제어하고, 차량의 대기 시간을 감소시키는 것을 목표로 한다.

학습된 강화학습 정책과 기존 고정 신호 방식의 성능을 비교하고, 교통량이 변화하는 상황에서 강화학습 정책의 대응 성능을 평가한다.

## 2. 사용 데이터

- 대상 교차로: 공릉역 교차로 (CROSS_ID: 1172)
- 데이터 기간: 2026년 11월 12일 ~ 11월 17일
- 학습 데이터: 11월 12일 ~ 16일
- 테스트 데이터: 11월 17일
- 데이터 단위: 5분 단위 방향별 직진 교통량

## 3. 강화학습 환경 설계

### State

- 현재 시간 (0~23시)
- 동서남북 각 방향의 대기 차량 수 구간
  - 0=0대
  - 1=1~10대
  - 2=11~30대
  - 3=31~60대
  - 4=61대
- 현재 교통 신호 상태 (청색, 황색, 적색)

### Action

- 0: 남북 방향 초록불, 동서 방향 빨간불
- 1: 동서 방향 초록불, 남북 방향 빨간불
- 행동 결정 주기: 1분

### Reward

R = -W - 0.1C

- W: 네 방향의 대기 차량 수 합계
- C: 신호 변경 여부

### 시뮬레이션 환경

- 1 Episode: 24시간 (1,440초)
- 차량 통과 간격: 2초
- 황색 신호: 3초
- 전적색 신호(동서, 남북 방향 모두 적색신호): 1초
- 신호 변경 후 출발 지연: 2초
  - ex)
  - 1-2-3-4 순으로
  - (1) 동서 신호 초록색, 남북 신호 빨간색
  - (2) 3초간 동서 신호 황색
  - (3)* 동서 신호가 빨간색으로 1초간 유지 (동서 신호가 빨간색으로 바뀜과 동시에 남북 신호가 초록색으로 바뀌지 않음)
  - (4) 이후 동서 신호 빨간색, 남북 신호 초록색 (남북 도로 위 차량은 2초간 출발 지연)

  -* (3)에서 전적색 신호를 추가한 이유: 교차로 내부의 잔류 차량이 안전하게 빠져나갈 시간을 확보하기 위해

## 4. 학습 방법

- 알고리즘: Q-Learning
- 행동 선택: Epsilon-Greedy
- Learning Rate: 0.1
- Discount Factor: 0.9
- Epoch: 30
- Epsilon: 0.3에서 0.02까지 감소

## 5. 실험 방법

### 실험 A: 실제 교통량 환경

학습된 Q-Learning 정책과 남북 4분, 동서 1분의 고정 신호 정책을 비교한다.
교통량은 평균 남북방향과 동서방향이 4.15 대 1로 차이가 났기 때문에 고정 신호 정책을 남북 1분, 동서 1분이 아닌 남북 4분, 동서 1분으로 정했다.

### 실험 B: 교통량 증가 환경

오전 8시부터 10시까지 동서 방향 교통량을 2배로 증가시킨 환경에서 두 정책의 성능을 비교한다.

### 평가 지표

- 누적 Reward
- 평균 대기 차량 수
- 최대 대기 차량 수
- 신호 변경 횟수*
- 하루 종료 시 대기 차량 수*

*신호 변경 시 동서와 남북방향 모두 차량이 통과하지 못하는 공백이 생기기 때문이다.
*평균 차량 수와 함께 활용하여 신호 제어 방식의 차량 처리 성능을 평가하기 위해서이다.
